# QQ 头像自动轮换

适用于 AstrBot v4.20+、`aiocqhttp`（OneBot v11）和 NapCat。插件通过 NapCat 的 `set_qq_avatar` 接口修改 **QQ 账号的真实头像**，不是修改 AstrBot WebUI 中的显示图片。

仓库：<https://github.com/qyd0321/astrbot_plugin_avatar_rotator>

## 功能

- 在 AstrBot 插件配置页批量上传或删除头像。
- 通过 QQ 管理员指令上传、查看、删除和立即切换头像。
- 按现实系统时间进行随机或顺序轮换，重启后保留计划。
- 支持暂停、恢复、失败重试与多 QQ 平台选择。

## 安装

1. 打开 AstrBot WebUI → **插件**。
2. 点击右下角的 **“+”**，选择 **从本地 ZIP 安装**。
3. 上传 `astrbot_plugin_avatar_rotator-v1.1.0.zip`。
4. 安装完成后重载插件；通常不需要重启整个 AstrBot。

默认启用自动轮换，间隔为 24 小时，但头像库为空时不会修改头像。首次安装不会立刻更换头像。

## 在 WebUI 上传头像

1. 打开“插件”并进入本插件的配置页面。
2. 找到“WebUI头像图库”，点击“上传文件”。
3. 选择或拖入一张或多张 JPG、JPEG、PNG、WebP、BMP 图片。
4. 关闭上传窗口后，点击页面右下角“保存”或“保存并关闭”。

删除“WebUI头像图库”列表里的文件后保存配置，该图片也会从轮换池中移除。WebUI 与 QQ 上传的图片会合并参与随机或顺序轮换。

## 在 QQ 上传头像

所有图库管理指令仅允许 AstrBot 管理员使用。

- 将一张或多张图片与 `/添加轮换头像` 放在同一条 QQ 消息中；或者先发送图片，再引用该图片发送 `/添加轮换头像`。
- 插件会自动下载、校验并转换成兼容性较好的 JPEG，然后保存到持久化图库。
- QQ 上传图库位于 AstrBot 的 `data/plugin_data/astrbot_plugin_avatar_rotator/avatars`；WebUI 上传文件由 AstrBot 保存在同一插件的持久化数据目录。插件重载、AstrBot 重启和普通版本更新不会清空它们。
- 每次最多上传 30 张；重复图片会自动跳过。

## WebUI Page

打开 AstrBot 侧边栏进入「头像库」页面,即可:

- 上传图片(支持拖拽或多选)
- 查看图库中所有头像的缩略图、尺寸、来源(`QQ` / `WebUI`)和裁切状态
- 点缩略图打开 1:1 裁切编辑器,拖拽框选裁切区域,保存到 `crops.json`
- 「立即换头像」按钮触发一次轮换并重置计时器

每次轮换头像时,插件会按每张图保存的裁切范围生成最终发送的 JPEG,再走 `set_qq_avatar` 上传。原图本身不会被裁切修改。

## 指令

| 指令 | 作用 |
| --- | --- |
| `/添加轮换头像` | 保存当前消息或引用消息中的图片，可一次添加多张 |
| `/轮换头像列表` | 显示图库及删除序号 |
| `/删除轮换头像 3` | 删除列表中的第 3 张 |
| `/立即换头像` | 立刻更换一次，并从现在重新计算下一次时间 |
| `/暂停头像轮换` | 暂停定时任务，保留图库与状态 |
| `/恢复头像轮换` | 恢复任务，并从现在计算一个完整间隔 |
| `/头像轮换状态` | 查看图库数量、上次/下次时间和最近错误 |

## 配置建议

- `interval_hours`：推荐 6～24 小时。虽然插件允许最低约 5 分钟，但不建议高频修改 QQ 资料。
- `selection_mode`：`random` 为不连续重复的随机轮换；`sequential` 为按上传时间依次轮换。
- `platform_id`：只有一个 QQ 机器人时留空。配置了多个 `aiocqhttp` 平台时，必须填写目标平台 ID。
- `change_on_start`：默认关闭，避免插件重载时突然更换头像。

如果同时启用了其他会修改 QQ 头像的插件（例如切换人格时同步头像），最终显示的是最后一次修改的头像，本插件会在下一次轮换时间再次覆盖它。
